Alexa-Controlled Home Automation with ESP32

A voice-controlled home automation system integrating Amazon Alexa with an ESP32 to physically operate conventional household switches using servo-actuated mechanisms.

ESP32 Alexa IoT Servo Control Embedded C

Overview

This project develops a low-cost voice-controlled home automation system using Amazon Alexa and an ESP32 microcontroller. Instead of relying on smart switches or smart plugs, servo motors physically operate existing wall switches, allowing conventional household appliances to be controlled through voice commands with minimal infrastructure changes.

What I built

  • Integrated Amazon Alexa with an ESP32 microcontroller to enable voice-controlled home automation.
  • Developed embedded software for receiving voice-triggered commands and controlling physical actuators.
  • Designed a servo-based switching mechanism capable of physically operating conventional electrical wall switches.
  • Implemented the complete control pipeline from Alexa voice commands to ESP32 communication and real-world actuator movement.
  • Designed the system as a retrofit solution, enabling existing household appliances to become voice-controlled without replacing electrical infrastructure.
