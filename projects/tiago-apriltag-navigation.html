Autonomous Navigation with AprilTags

Autonomous navigation and task execution for PAL Robotics' Tiago robot, using AprilTag-based localization for reliable positioning in structured environments.

ROS FlexBE Docker AprilTags Autonomous Navigation Mobile Robotics

Overview

This project focused on developing an autonomous navigation and task execution framework for PAL Robotics' Tiago robot. By combining AprilTag-based localization, ROS navigation, FlexBE state machines, and Dockerized deployment, the system enabled reliable autonomous navigation and service robot task execution in structured indoor environments.

What I built

  • Developed an autonomous navigation system for PAL Robotics' Tiago robot using AprilTag-based localization, enabling accurate positioning and reliable navigation in structured indoor environments.
  • Designed and implemented FlexBE state machines to automate service robotics tasks, including table cleaning, object sorting, and task sequencing.
  • Integrated ROS navigation, perception, localization, and manipulation packages into a unified robotic software architecture.
  • Configured Dockerized ROS development environments, enabling reproducible deployment and simplified software distribution.
  • Validated autonomous navigation, localization, and task execution through simulation and experimental testing.
  • Developed a modular software architecture that simplified future extension of navigation, perception, and manipulation capabilities.
