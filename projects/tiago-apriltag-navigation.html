Autonomous Navigation with AprilTags

Autonomous navigation and task execution for PAL Robotics' Tiago robot, using AprilTag-based localization for reliable positioning in structured environments.

ROS FlexBE Docker AprilTags Autonomous Navigation Mobile Robotics

Overview

A service-robotics pipeline: reliable localization through AprilTags, task automation through a state machine, and a fully Dockerized deployment so the whole stack is reproducible.

What I built

  • Developed an autonomous navigation system for PAL Robotics' Tiago robot using AprilTag-based localization, enabling accurate positioning and reliable task execution in structured environments.
  • Automated service robotics tasks including table cleaning and object sorting through a custom FlexBE state machine coordinating navigation, perception, and manipulation workflows.
  • Integrated multiple ROS packages and deployed the complete robotic software stack using Docker, improving modularity, reproducibility, and system maintainability.
