ACADEMIC PROJECT

Elevator Interface & Control System

A complete elevator automation system built in Siemens TIA Portal — floor selection, movement control, and door operation via PLC ladder logic.

Siemens TIA Portal Factory I/O PLC Ladder Logic HMI Design Industrial Automation

Overview

A classic industrial-automation build: elevator control logic implemented entirely in PLC ladder logic, paired with a real-time HMI and validated against realistic sensor and actuator behavior before ever touching hardware.

What I built

  • Developed a complete elevator automation system using Siemens TIA Portal, implementing floor selection, movement control, and door operation through PLC ladder logic.
  • Designed an HMI for real-time monitoring and user interaction, improving system usability and operational visibility.
  • Validated elevator control logic in Factory I/O through realistic simulation of sensor feedback, actuator behavior, and safety interlocks.
Context Bachelor Academic Project · Parul University
