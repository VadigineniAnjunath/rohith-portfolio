Virtual Poster Positioning (AR)

Computer-vision-driven augmented reality — placing virtual posters accurately and stably into real-world scenes using marker-based tracking.

OpenCV ArUco Markers Camera Calibration Augmented Reality Pose Estimatin

Overview

This project focused on developing an augmented reality application using OpenCV and ArUco markers to accurately place virtual objects in real-world environments. By combining camera calibration, marker detection, and pose estimation, the system achieved stable real-time positioning of virtual content relative to the physical environment.

What I built

  • Developed a computer vision pipeline using OpenCV for real-time ArUco marker detection and tracking.
  • Performed camera calibration to estimate intrinsic camera parameters and improve pose estimation accuracy.
  • Implemented marker pose estimation to compute the 3D position and orientation of detected markers relative to the camera.
  • Developed an augmented reality application that accurately positioned and rendered virtual posters onto physical surfaces using marker-based tracking.
  • Optimized real-time tracking performance to maintain stable virtual object placement during camera movement and viewpoint changes.
  • Validated the system under different viewing angles, distances, and lighting conditions to improve robustness and tracking reliability.
