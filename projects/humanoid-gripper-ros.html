MASTER'S THESIS

Controlling a Humanoid Robotic Gripper in ROS

A complete ROS-based software framework for a 5-finger dexterous humanoid robotic gripper — spanning simulation, sensing, motion planning, control, and hardware integration, from CAD to closed-loop control.

ROS1 Gazebo MoveIt! C++ STM32 Fusion 360 HMI

Overview

This thesis set out to answer one question: can a 5-finger humanoid gripper sense, plan, and act reliably enough to trust near real objects? The answer became a full-stack ROS framework spanning mechanical design, simulation, low-level sensing, motion planning, and a control interface a human could actually operate.

What I built

  • Built URDF robot models directly from Fusion 360 mechanical CAD designs and integrated them into Gazebo for validation and testing.
  • Set up Dockerized ROS environments with MoveIt!-based motion planning for dexterous manipulation and trajectory execution.
  • Wrote custom C++ tactile and barometric pressure sensor plugins, ROS nodes, and controllers for real-time monitoring and interaction feedback.
  • Developed a C++ library bridging ROS with the gripper's firmware, plus SOCAT-based communication for real-time sensor streaming through a custom HMI.
  • Designed a web-based HMI for robot control, sensor visualization, and system interaction across simulation and hardware.
