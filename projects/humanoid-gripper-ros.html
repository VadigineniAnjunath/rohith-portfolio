MASTER'S THESIS

Design and Implementation of Controlling a Humanoid Robotic Gripper in ROS

A complete ROS-based software framework for a 5-finger dexterous humanoid robotic gripper — spanning simulation, sensing, motion planning, control, and hardware integration, from CAD to closed-loop control.

ROS1 Gazebo MoveIt! C++ STM32 Fusion 360 HMI

Overview

This master's thesis focused on designing and implementing a complete ROS-based control framework for a 5-finger humanoid robotic gripper. The project integrated mechanical design, robot simulation, motion planning, tactile sensing, hardware communication, and human-machine interaction into a unified robotic system capable of both simulated and real-world operation.

What I built

  • Designed and developed the complete URDF/Xacro robot model from Fusion 360 CAD assemblies, enabling accurate simulation and visualization in Gazebo and RViz.
  • Configured Dockerized ROS development environments and integrated MoveIt! for motion planning, trajectory execution, and dexterous manipulation.
  • Developed custom C++ Gazebo plugins and ROS nodes for pressure and contact sensing, enabling real-time tactile feedback and object interaction monitoring.
  • Built a C++ communication library connecting ROS with the gripper's STM32 firmware, using SOCAT-based serial communication for reliable real-time sensor and actuator data exchange.
  • Designed and developed a web-based HMI for robot control, gesture execution, sensor visualization, and system monitoring across both simulation and physical hardware.
  • Developed ROS controllers for joint control, trajectory execution, and hardware interfacing, enabling seamless switching between simulation and the physical robotic gripper.
  • Integrated pressure sensors, contact sensors, and joint-state feedback into the ROS ecosystem, providing real-time visualization and monitoring tools for system validation.
  • Validated the complete software stack through simulation-to-real deployment, demonstrating coordinated motion planning, hardware communication, tactile sensing, and interactive robot control.
