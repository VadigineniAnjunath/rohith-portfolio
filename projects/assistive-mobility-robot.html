PERSONAL PROJECT

Inbangging Roboter(Assistive Mobile Robot with Robotic Arm)

A vehicle fitted with a robotic arm for physically handicapped users, able to pick up and transport everyday items alongside autonomous navigation.

Arduino IDE Python Assistive Technology Robotic Arm

Overview

Built to explore practical assistive robotics: a mobility platform paired with a simple pick-and-place arm, aimed at giving physically handicapped users a way to retrieve and move everyday items independently.

What I built

  • Designed and developed an autonomous mobile robotic platform capable of navigating indoor environments with minimal user intervention.
  • Integrated a robotic arm onto the mobile platform, enabling autonomous pick-and-place operations for transporting everyday objects.
  • Developed the complete embedded control software in C++ using the Arduino IDE, coordinating vehicle movement, robotic arm control, and actuator operation.
  • Integrated sensors, motor drivers, and actuators to achieve reliable navigation and object manipulation.
  • Implemented motion control algorithms for coordinated vehicle movement and robotic arm operation.
  • Validated the complete robotic system through functional testing, demonstrating autonomous navigation and object transportation.
