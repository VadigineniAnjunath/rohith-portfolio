ROS-Based SLAM & Object Detection Pipeline

A modular ROS2 perception pipeline combining camera acquisition, real-time object detection, and visualization — built toward semantic mapping and 3D localization.

ROS2 OpenCV YOLO Gazebo MuJoCo RTAB-Map CvBridge

Overview

A ground-up perception stack: image streaming, detection, and visualization as composable ROS2 nodes, with an eye toward full semantic mapping rather than just bounding boxes.

What I built

  • Built custom ROS2 nodes for image streaming, camera calibration, object detection, and dataset collection using standard ROS2 communication interfaces.
  • Integrated YOLO-based real-time object detection with ROS2 vision pipelines, publishing structured detection data for downstream robotic perception applications.
  • Developed and validated perception workflows in Gazebo and MuJoCo simulation environments with a focus on future SLAM integration and sim-to-real deployment.
  • Extending the system toward semantic mapping and 3D object localization through RTAB-Map, depth sensing, TF transformations, and sensor fusion techniques.
