ROS-Based SLAM & Object Detection Pipeline

A ROS2 SLAM pipeline focused on real-time localization and mapping — building a complete map of the environment while integrating YOLOv2 object detection for bounding-box-level scene understanding. Still actively in progress.

ROS2 OpenCV YOLO Gazebo MuJoCo SLAM RTAB-Map CvBridge

Overview

A ground-up perception stack: image streaming, detection, and visualization as composable ROS2 nodes, with an eye toward full semantic mapping rather than just bounding boxes.

What I built

  • Built a ROS2 SLAM pipeline focused on real-time localization and mapping, using an Intel RealSense depth camera to generate a complete map of the environment as the robot moves through it.
  • Integrated YOLOv2-based real-time object detection into the perception pipeline, publishing bounding-box detections alongside the SLAM map for richer scene understanding.
  • Developed custom ROS2 nodes for RealSense image and depth streaming, camera calibration, and dataset collection using standard ROS2 communication interfaces.
  • Leveraged the RealSense camera's depth data for point-cloud generation and obstacle-aware mapping, feeding directly into the SLAM localization loop.
  • Validated the pipeline in Gazebo and MuJoCo simulation environments, with the project still actively in progress toward full semantic mapping and 3D object localization.
