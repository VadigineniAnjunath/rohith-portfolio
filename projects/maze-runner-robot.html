PERSONAL PROJECT

Maze Runner Robot

An autonomous maze-navigating robot built from scratch — sensor-driven pathfinding with closed-loop control for smooth, obstacle-free traversal.

Embedded C PID Control IR Sensors Ultrasonic Sensors

Overview

This project focused on designing and building a fully autonomous maze-solving robot from the ground up. The robot combined real-time sensor processing, closed-loop PID control, and path-planning algorithms to navigate unknown maze environments while maintaining stable motion and avoiding collisions.

What I built

  • Designed and built a fully autonomous mobile robot, integrating embedded electronics, motor drivers, and a custom mechanical chassis.
  • Integrated IR and ultrasonic sensors for real-time wall detection, obstacle avoidance, and distance measurement.
  • Developed an autonomous maze-solving algorithm using real-time sensor feedback for path planning and navigation.
  • Implemented closed-loop PID control to achieve smooth steering, accurate wall following, and stable robot motion.
  • Developed embedded control software in C for real-time sensor acquisition, decision-making, and motor control.
  • Validated autonomous navigation performance through iterative testing, sensor calibration, and controller tuning in different maze layouts.
