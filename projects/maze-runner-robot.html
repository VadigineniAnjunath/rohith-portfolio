PERSONAL PROJECT

Maze Runner Robot

An autonomous maze-navigating robot built from scratch — sensor-driven pathfinding with closed-loop control for smooth, obstacle-free traversal.

Embedded C PID Control IR Sensors Ultrasonic Sensors

Overview

Built entirely from the ground up: chassis, sensors, and control loop. The goal was smooth, reliable maze traversal without ever touching a wall, using nothing but onboard IR and ultrasonic sensing.

What I built

  • Constructed the robot from scratch, integrating IR and ultrasonic sensors for wall and obstacle detection.
  • Designed a maze-solving pathfinding algorithm layered on top of real-time sensor input.
  • Implemented PID control for stable, efficient maze traversal and adaptive-speed obstacle avoidance.
