Vision-Language-Action Pick-and-Place on Franka FR3

An intelligent robotic manipulation pipeline integrating Vision-Language-Action (VLA) models with the Franka FR3 robotic arm, enabling instruction-driven object manipulation beyond traditional motion planning.

Franka FR3 VLA Models Robot Manipulation Motion Planning Python

Overview

This project began with a fully functional pick-and-place pipeline on the Franka FR3 robotic arm using conventional motion planning techniques. The current phase extends the system by integrating Vision-Language-Action (VLA) models, enabling the robot to interpret visual observations and natural language instructions for more flexible, intelligent manipulation. The project is actively exploring AI-driven robotic manipulation capable of generalizing beyond fixed, pre-programmed tasks.

What I built

  • Developed a complete pick-and-place manipulation pipeline for the Franka FR3 robotic arm.
  • Integrated robot perception, manipulation, and motion execution into a unified robotic workflow.
  • Currently integrating Vision-Language-Action (VLA) models to enable instruction-driven robotic manipulation.
  • Exploring AI-based manipulation strategies that generalize grasping and placement beyond fixed, pre-programmed trajectories.
  • Evaluating the integration of foundation models for intelligent robotic task execution in real-world manipulation scenarios.
