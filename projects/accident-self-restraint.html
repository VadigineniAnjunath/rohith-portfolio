PERSONAL PROJECT

Accident Self-Restraint System

Ultrasonic, LDR, gas (MQ-3), and IR sensors combined for obstacle avoidance, automatic headlight control, and alcohol-based safety interlocks.

Arduino C++ Sensor Fusion Safety Systems

Overview

A multi-sensor safety system exploring how cheap, commodity sensors can combine into meaningful automotive safety behavior — obstacle avoidance, adaptive lighting, and a hard interlock when alcohol is detected.

What I built

  • Combined ultrasonic, LDR, MQ-3 gas, and IR sensors into a comprehensive obstacle-avoidance mechanism.
  • Implemented automatic headlight control that responds to ambient environmental conditions.
  • Built an alcohol-sensor-based system management layer that restrains operation when unsafe conditions are detected.
  • Wrote the full control algorithm in Arduino C++, integrating real-time sensor data for dynamic response.
